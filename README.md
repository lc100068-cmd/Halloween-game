# ハロウィンAIラボ

マルシェのハロウィンAIブース用のアプリ集です。タブレットやお客さんのスマホで、「AIへの頼み方」で結果が変わるおもしろさを体験できます。

公開先：https://lc100068-cmd.github.io/Halloween-game/

| ファイル | アプリ | 内容 |
|---|---|---|
| `index.html` | アプリ選択画面 | 3つの体験から1つえらぶ |
| `zukan.html` | AIモンスター図鑑 | 質問の答えから、ChatGPT や Gemini に写真と一緒に貼る「モンスターカードの呪文」をつくる |
| `quiz.html` | オバケのAIクイズ | オバケのポルタが「AIを使いこなすための6つの掟」から出すクイズ（各掟2問のうち1問ずつ、全6問） |
| `song.html` | ハロウィンソング工房 | 名前や好きなものから、歌詞の呪文（ChatGPT / Gemini 用）と曲調の呪文（Suno などの音楽AI用）をつくる |
| `common.css` | 共通スタイル | index / quiz / song で読み込む（zukan はインラインスタイル） |

- どのページも上部の切り替えバー（トップ／図鑑／クイズ／ソング）で、1タップでアプリを切り替えられます
- APIキー不要。すべてブラウザの中で動き、入力した内容はどこにも送信されません
- 写真はアプリには読み込まず、AIに呪文と一緒に自分で添付します
